# Frontline — стратегический прототип

Мобильный браузерный прототип с условной картой и вымышленными сторонами. Это не готовая коммерческая игра, а стартовая версия для тестирования интерфейса и основных циклов.

## Уже реализовано
- Выбор стороны игрока: Северная или Южная коалиция; вторая сторона действует под управлением простого игрового ИИ.
- Три варианта старта: начальный кризис, затяжное противостояние, свободная дата.
- Условная карта с городами, реками, дорогами, лесными зонами, линией контроля и значками подразделений.
- Приближение/отдаление и перемещение карты мышью или касанием.
- Карточки подразделений: личный состав, готовность, снабжение, мораль, опыт и статус.
- Создание и переименование подразделений, изменение позиции на условной карте, выбор статуса.
- Пополнение личного состава, восстановление снабжения, расширение резерва.
- Политические решения и журнал событий.
- Автоматическое течение времени, простые действия ИИ, сохранение в localStorage.

## Как запустить локально
1. Распакуй архив.
2. Открой `index.html` в браузере. Для некоторых браузеров удобнее запуск через локальный сервер.
3. Для GitHub Pages: загрузи `index.html`, `style.css`, `game.js` в корень репозитория, затем открой **Settings → Pages** и выбери публикацию из ветки `main`, папка `/ (root)`.

## Управление
- Нажатие на значок подразделения или карточку выбирает его.
- Кнопки `+` и `−`, колесо мыши или жесты меняют масштаб карты.
- Перетаскивай карту, чтобы перемещаться по ней.
- Время идёт автоматически после нажатия «Продолжить»; «Пропустить день» двигает симуляцию на один день.
- Сохранение хранится в локальном браузере и не синхронизируется между устройствами.

## Ограничения прототипа
- Карта и стороны вымышленные, не географическая карта реального конфликта.
- ИИ упрощённый и демонстрационный, а не полноценный стратегический ИИ.
- Нет сетевой игры, аккаунтов, реальной синхронизации, озвучки или готовых мобильных сборок.
- Значения и последствия игровых решений условные.
